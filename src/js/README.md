# JavaScript-модули

`app.js` — точка входа. Модули подключаются обычным `import`, а esbuild собирает их в один скрипт для `build/`. Порядок файлов в `gulpfile.mjs` больше не нужно менять.

- `app/example-module.js` — место для поведения нового проекта.
- `modules/tabs.js` — вкладки с управлением клавиатурой; работает с блоками `[data-tabs]`.
- `modules/reveal.js` — добавляет `is-visible` элементам `[data-reveal]` при появлении в области просмотра и учитывает уменьшение движения.
- `utils/dom.js` — поиск одного или нескольких элементов.
- `settings.js` — общие настройки модулей.

У стартовой страницы нет вкладок и анимируемых элементов. Модули готовы к использованию, но не добавляют лишнее поведение без соответствующей разметки. Для новой функции создайте отдельный файл и импортируйте его в `app.js`.
